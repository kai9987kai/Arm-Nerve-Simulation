# Arm-Nerve-Simulation
 realistic simulation of the arm's nervous system with interactive features
Features
Anatomy
6 major arm nerves with anatomically accurate paths: Musculocutaneous, Median, Ulnar, Radial, Axillary, and Medial Cutaneous nerves
Brachial plexus visualization showing C5-T1 nerve roots
Branch networks for each nerve (digital branches, motor branches, cutaneous branches)
Toggleable layers: bones, muscles, blood vessels, labels
Signal Simulation
Action potential propagation with realistic waveform visualization
Motor signals (brain → fingers), sensory signals (fingers → brain), and reflex arcs
Adjustable conduction velocity (5-120 m/s matching real fiber types)
Saltatory conduction effect with nodes of Ranvier pulsation
View Modes
Anatomical — standard nerve layout
Dermatomes — skin innervation zones by spinal root
Myotomes — muscle groups by spinal root
Cross-section — transverse view showing nerve positions relative to bones and vessels
Clinical Information
Click any nerve for motor/sensory territories, root levels, and clinical injury patterns (carpal tunnel, wrist drop, claw hand, etc.)
